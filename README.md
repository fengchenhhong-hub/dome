# A Room of Frames

A personal film and commercial-content portfolio, with a small interactive screening room.

This deployment contains only the selected, already-public works and their production notes. The graduation film in post-production is a status card, not an available complete film.

The manual Pages workflow imports hash-verified public assets once, commits them into this repository, and publishes `public/`. Subsequent runs reuse the stored files, so the published copy can continue independently of the previous hosting provider.

No custom domain or paid subscription is required. GitHub Pages service limits still apply. Availability on a particular domestic network must be tested using that network.
